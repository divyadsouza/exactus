# Data
## Collected from nicpopovic/vital_articles_synthetic_information_extraction
- 5,010 rows of Wikipedia-derived synthetic extraction data
- Raw file (`train-00000-of-00001.parquet`) has a SQL-like structure with integer ID foreign keys across `entities`, `relations`, `entity_types`, and `relation_types` columns

## Cleaned Data — `nuextract_prompts.parquet`
Generated by `scripts/transform_dataset.py`. Three columns only:
- `text` — original source text
- `template` — per-row NuExtract JSON template, reverse-engineered from entity/relation types
- `target` — de-normalized JSON with integer IDs resolved to entity names, grouped by type
